#KisanMitra – Smart Farmer Marketplace & Advisory Platform

KisanMitra is a full-stack web application designed to empower farmers and customers by combining an **agriculture marketplace**, **smart crop prediction**, and **real-time agricultural news analysis** in one platform.

---

## Core Features
---
## 🌱 Smart Crop Prediction (AI-based)
KisanMitra provides **crop recommendations based on soil and environmental factors**.
### Input Parameters
- Soil Type
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Rainfall
- pH Level
